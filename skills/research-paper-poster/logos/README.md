# Institution Logos

Place commonly-used institution logo images here. The poster skill will auto-detect and use them.

## Naming Convention

Use lowercase names with hyphens, e.g.:
- `peking-university.png`
- `tsinghua-university.png`
- `mit.png`
- `stanford.png`
- `cmu.png`
- `nvidia.png`
- `microsoft-research.png`
- `google-research.png`
- `meta-ai.png`
- `openai.png`

## Requirements

- **Format**: PNG with transparent background preferred
- **Resolution**: At least 500px width for A0 poster quality
- **File size**: Keep under 2MB per logo

## Usage

The poster skill will:
1. Auto-detect logos from this directory
2. Allow user to specify custom logo paths via `— logo: /path/to/logo.png`
3. Place logos in the title bar or footer of the poster
